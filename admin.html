Connexion

Les médias du site sont enregistrés dans le fichier medias.json du dépôt GitHub. Pour les modifier, connectez-vous avec une clé d'accès GitHub (jeton personnel).

Comment obtenir une clé d'accès ?
  1. Sur GitHub : Settings → Developer settings → Personal access tokens → Fine-grained tokens, puis Generate new token.
  2. Dans Repository access, choisissez Only select repositories et sélectionnez le dépôt du site.
  3. Dans Permissions → Repository permissions, mettez Contents sur Read and write.
  4. Copiez la clé générée et collez-la ci-dessus. Ne la partagez avec personne.
